# Santhosh P — Portfolio

Master-level portfolio UI/UX built with plain **HTML / CSS / JavaScript** (no frameworks, no build step).

## Sections

- Hero with terminal showcase & typed roles
- About / Professional Summary
- Skills (chips + animated progress bars)
- Experience timeline
- Featured Projects
- Education
- Certifications & Awards
- Contact & Footer

## Run locally

Just open `index.html` in a browser, or serve it:

```bash
# any static server works
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploy to GitHub Pages

1. Push this repo to GitHub.
2. In the repo: **Settings → Pages → Branch** → select `main` / root.
3. Your site goes live at `https://<username>.github.io/<repo-name>/`.

## Tech

- HTML5, CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (IntersectionObserver, typing effect, mobile nav)
- Google Fonts: Sora + JetBrains Mono
